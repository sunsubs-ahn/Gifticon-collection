# 🎁 Gifticon Collection

기프티콘과 멤버십 카드를 **기기 안에만** 모아 두는 파스텔 톤 PWA입니다.
서버로 아무것도 보내지 않고, 모든 데이터는 브라우저(IndexedDB) 안에만 저장됩니다.

## 쓰는 방법

1. 폰 브라우저에서 아래 주소를 엽니다.
   https://sunsubs-ahn.github.io/Gifticon-collection/
2. 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱처럼 열립니다.
3. `+ 쿠폰 추가`에서 기프티콘 **사진을 올리거나 문자 내용을 붙여넣으면**
   쿠폰번호·만료일·브랜드·상품명을 자동으로 읽어 채워 줍니다.

## 기능

- 폴더: `전체` · `사진첩` · `문자` · `카톡 선물하기` · `스타벅스` · `기타` · `멤버십 카드`
- 유효기간 임박순 정렬, 브랜드·상품명·쿠폰번호 검색, 사용완료 보기
- `쿠폰 열기`: 원본 사진 + 쿠폰번호 기반 **Code128 바코드** + 번호 복사
- 멤버십 카드: 카드 번호만 입력하면 바코드를 만들어 저장, 누르면 크게 표시
- 만료 1주일 전 알림: 앱 내 `7일 내 만료` 표시 · 브라우저 알림 · `임박 알림 .ics`(캘린더 등록)
- `JSON 백업 저장` / `백업 불러오기` 로 기기 이동·복원
- 오프라인에서도 열립니다(Service Worker 캐시)

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `styles.css` | 파스텔 디자인 (기기 기본 폰트) |
| `app.js` | 저장소·바코드·자동 인식·백업·알림 |
| `manifest.webmanifest` | PWA 설정 |
| `sw.js` | 오프라인 캐시 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 참고

- 이미지 글자 읽기(OCR)는 처음 한 번 Tesseract.js를 CDN에서 내려받습니다.
  인터넷이 없으면 사진은 그대로 저장되고, 문자 내용을 붙여넣어 `자동 인식`을 쓰면 됩니다.
- 주소는 공개지만 접속한 사람은 자기 브라우저의 빈 목록만 보게 됩니다.
